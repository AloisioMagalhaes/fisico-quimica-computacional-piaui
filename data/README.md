# Dados gerados

Os JSON de cálculos quânticos, o CSV consolidado e os gráficos são artefatos das execuções do GitHub Actions. Cada artefato deve ser associado ao identificador da execução, ao commit e ao ambiente Python.

Os dados atuais são benchmarks moleculares pequenos. Não representam cinzas, material radioativo, grafite periódico, diamante sintético ou bateria.
